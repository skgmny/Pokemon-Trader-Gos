## 1. 목적과 추적 범위

Android 첫 버전의 MVP-01~MVP-07과 8개 비즈니스 규칙을 [SRS](요구사항명세서-SRS.md) 수용 기준, [유스케이스명세서](유스케이스명세서.md), 검증 예정 항목과 연결한다. 기획 출처는 [서비스기획서](../00-기획/서비스기획서.md)와 [비즈니스정책서](../00-기획/비즈니스정책서.md) v0.1이다. 화면 관련 출처는 [DESIGN.md](../../../DESIGN.md)다.

## 2. 상태 정의

- **요구사항 초안** · 아래 모든 기능·비기능 요구사항은 MVP 필수 범위의 초안으로 G1 검토 전이다.
- **설계 초안 연결** · 해당 요구사항을 Phase 2와 Phase 3 설계 위치에 연결했다. 구현 위치와 증빙은 후속 단계에서 연결한다.
- **예정 테스트** · 수용 기준으로부터 식별자를 부여한 시나리오다. 실제 테스트 문서와 실행 결과는 Phase 5에서 연결한다.
- **미실행** · 실행 결과와 증빙이 없는 상태다.

## 8. 갱신과 단계 검토

G1에서는 적용 범위와 출처, SRS 수용 기준이 빠짐없이 연결됐는지 검토한다. 시스템·상세 설계와 구현이 진행되면 각 행에 설계 절과 구현 위치를 추가한다. 테스트 시에는 후보 빌드와 실제 테스트 ID, 판정과 증빙을 연결한다. 승인과 변경 기록은 [단계별 검토 체크리스트](../08-검토/단계별검토-체크리스트.md)에 남긴다.
