# PokemonGO-market

## 포켓몬 카드 거래·랜덤팩 앱 기획안

**운영자가 검수한 실물 포켓몬 카드를 앱에서 사고, 랜덤팩으로 뽑고, 보관하거나 다시 팔 수 있는 서비스예요.** 실물 카드는 운영자 창고에 있고, 앱의 내 컬렉션에서 내가 보유한 카드를 확인할 수 있어요. 배송을 신청하기 전까지는 카드가 창고에 있으므로, 다시 팔 때 사용자가 택배를 보낼 필요가 없어요.

포카마켓의 입고판매 방식에서 **운영자가 카드를 받아 검수하고 판매와 배송을 맡는 흐름**을 참고해요. 이 앱에서는 검수를 통과한 포켓몬 카드를 개별 구매 상품이나 온라인 랜덤팩 재고로 활용해요. [포카마켓 입고판매 안내](https://contents.phocamarket.com/how-to-use/stock-sale)

## 1. 카드 보내기와 검수

1. 사용자가 카드 이름, 카드 번호, 희귀도, 앞뒷면 사진을 등록하고 운영자에게 배송해요.
2. **하위 카드 N장을 제출할 때 상급 카드 1장을 함께 제출하는 규칙**을 적용해요. 예를 들어 하위 카드 5장에 상급 카드 1장이 필요하다면, 신청 화면에서 충족 여부를 바로 보여줘요. `5장`은 예시이고 실제 장수와 상급 희귀도 기준은 운영자가 설정해요.
3. 운영자는 실물의 정품 여부와 상태를 확인하고, 카드별로 통과·하자·반려 결과와 사유를 기록해요. 함께 보낸 상급 카드가 검수를 통과하지 못해 조건을 충족하지 못하면, 해당 묶음의 매입을 보류하고 결과를 안내해요.
4. 사용자가 검수 후 제시된 매입가에 동의하면 정산 잔액을 지급해요. 매입이 확정된 카드는 운영자 재고에 등록해 개별 판매 또는 랜덤팩에 배정해요.

## 2. 카드 구매와 랜덤팩

- **개별 구매**에서는 원하는 카드를 검색하고, 희귀도·검수 상태·실물 사진·가격을 보고 구매해요.
- **랜덤팩**에서는 팩 가격과 희귀도별 확률을 확인하고 개봉해요. 개봉하면 운영자가 보관 중인 실물 카드 한 장이 내 컬렉션에 들어와요.
- 실물 카드마다 재고 번호를 붙여요. 같은 종류의 카드가 여러 장 있어도 각각의 상태와 소유자를 관리하고, 같은 실물 한 장이 두 사람에게 배정되는 일을 막아요.

## 3. 내 컬렉션과 정산

예를 들어 랜덤팩에서 **로켓단의 뮤츠 ex UR**을 뽑았다면, 컬렉션에 보관하거나 배송을 신청할 수 있어요. 운영자에게 다시 팔고 싶다면 앱에서 매입가를 확인하고 수락해요. 카드는 이미 창고에 있으므로 **카드 소유권을 운영자에게 넘기고 정산 잔액을 받는 과정**이 앱 안에서 끝나요. 정산 잔액은 앱에서 카드나 팩을 구매할 때 쓰거나 계좌 출금을 신청하는 구조예요.

## 4. 첫 버전과 확인 기준

첫 버전은 **테스트 잔액**으로 입고 신청 → 검수 → 재고 등록 → 개별 구매 또는 랜덤팩 개봉 → 컬렉션 → 배송 요청 또는 재매입까지 연결해요. 운영자 화면에서 검수 결과, 매입가, 재고, 배송 요청을 처리할 수 있게 해요. 실제 결제와 출금은 유료 랜덤팩 및 정산 방식의 출시 요건을 검토한 뒤 연결해요.

검증할 때는 상급 카드가 부족한 입고 신청이 제한되는지, 검수에서 반려된 카드가 판매에 올라가지 않는지, 두 사람이 동시에 구매해도 한 장만 배정되는지 확인해요. 배송을 신청한 카드의 재매입이 제한되고, 재매입 정산이 한 번만 반영되는지도 확인해요.
